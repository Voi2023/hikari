App không tự tính phí ship. Phí hiển thị cho khách là phí đơn vị giao hàng báo về tại thời điểm đặt (spec 03) — bảng trên chỉ là mức tạm tính khi API đối tác không phản hồi, và khi đó phải nói rõ với khách là tạm tính: chênh lệch phí ship ở bước cuối là lý do khách bỏ giỏ hàng nhiều nhất.
❓ Chờ chốt đối tác: đang thiết kế theo ShippingProvider với BE (be.com.vn). BE chưa chắc có Open API tự phục vụ — nếu không có hợp đồng B2B + API key thì chuyển sang Ahamove / GrabExpress mà không phải sửa phần còn lại của hệ thống.
