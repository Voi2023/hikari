# Logo & hình ảnh gốc

Chủ quán đã gửi **2 logo** và **2 ảnh menu** trong hội thoại. Vì Claude nhận dưới dạng hình xem trực tiếp
(không phải file), **các file gốc cần được đặt vào đây thủ công**:

## Cần bổ sung (kéo file vào thư mục)

| File cần đặt | Mô tả | Vị trí |
|---|---|---|
| `hikari-logo-black.(svg\|png)` | Logo "Hikari — vegetarian cafe" chữ đen | `docs/assets/logo/` |
| `hikari-logo-white.(svg\|png)` | Logo bản trắng (nền tối) | `docs/assets/logo/` |
| `hikari-icon.png` | Icon mini app vuông ≥512×512 (Zalo yêu cầu) | `docs/assets/logo/` |
| `mon-mi-2025-03.jpg` | Ảnh menu món mì (bản thg 3/2025) | `docs/assets/menu/` |
| `do-uong-2024-10.jpg` | Ảnh menu đồ uống (bản thg 10/2024) | `docs/assets/menu/` |

> Dữ liệu chữ trong 2 ảnh menu **đã được trích** sẵn vào [`../data/menu.json`](../data/menu.json).
> Prototype tạm dùng logo chữ (text) theo brand cho tới khi có file vector gốc.
